# 강남구 관광 진단 테스트

한국관광 데이터랩에서 내려받은 강남구 ZIP을 읽어, 관광 담당자가 확인할 대시보드와 AI 전략 보고서 흐름을 빠르게 검증하는 Streamlit 시연 화면입니다. 최종 서비스의 React + Vite 구조를 대체하지 않습니다.

## 포함된 실제 지표

- 월별 방문자 수(연인원), 내비게이션 검색량, SNS 언급량
- 내국인 관광소비액과 방문 1회당 추정 소비액
- 숙박 방문 비율과 평균 숙박일수
- 12개월 자료로 수행한 시간순 기준선·선형회귀·랜덤포레스트 시연 비교

## 실행

1. `.env`의 `DATA_SOURCE_DIR`을 확인한다.
2. AI 보고서를 사용하려면 `OPENAI_API_KEY`를 `.env`에 직접 넣는다.
3. 가상환경을 만들고 의존성을 설치한 뒤 실행한다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\streamlit.exe run app.py
```

## 한계

자료 기간이 2025-08~2026-07의 12개월이므로, 모델 결과는 교육·화면 시연용이다. 시간순 held-out 검증을 포함한 정식 예측 모델은 최소 36개월 이상의 같은 정의·같은 지역 단위 자료를 확보한 뒤 만든다.
