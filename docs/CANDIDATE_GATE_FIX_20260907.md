# 후보 설계 검증 수정 (2026-09-07)

> 2026-09-09 운영 변경: 이 문서의 전면 차단 정책은 D-112에서 범위를 좁혔다. 서버 계약으로 안전하게 보정할 수 있는 오류는 `needs_evidence` 검토용 본문으로 이어지고, 복구할 수 없는 critical 근거 오류만 계속 차단한다. 아래 내용은 변경 전 원인과 검증 기록이다.

사용자가 제공한 원주 생성 결과를 기준으로 점검했다. 기존에는 후보 보완에 실패하거나 보완 후 누락이 남아도 본문 작성으로 넘어갔다. 본문 작성기는 상위 후보 JSON을 수정하지 못하므로 이 경로를 차단한다.

- 사례 ID는 후보뿐 아니라 strategy_brief.supporting_case_ids와 recommended_case_ids까지 등록 목록과 대조한다.
- 후보의 candidate_type 다양성과 selected_candidate_id의 존재를 확인한다.
- 예산 체계 구축/마련을 관광사업 제목으로 사용하는 경우도 검출한다.
- 기존의 제한적 후보 보완 후 문제들이 남으면 HTTP 422 / TRANSFERABILITY_CANDIDATE_VALIDATION_FAILED로 종료한다. 본문 및 후속 검수 호출은 하지 않는다. 이미 수행한 자료 조사 비용이 없었다는 의미는 아니다.
- 오류에는 보완하지 못한 문제를 명시한다. 새 원자료 업로드가 필요한 문제라고 단정하지 않는다.
- 원본 저장 보고서와 ML 예측치는 변경하지 않는다. 재생성 성공이나 기획 품질 향상을 보장하는 수정은 아니다.

검증: planning_requirements와 report_orchestrator 단위 테스트 37개 통과. 유료 API나 GPU를 호출한 실생성 검증은 아직 하지 않았다.

남은 확인: 웹 본문과 PPT 견적의 단일화, 사례 원 지역 표시, 실행 목표의 명시적 설계 및 실제 생성 회귀 검증. 이를 완료하기 전 전체 문제 해결로 표시하지 않는다.
