# 지역별 기획안 준비 상태 점검

## 판정 범위

활성 등록 시군구 89개를 실제 생성용 원자료 조회 및 저장 ML 경로로 검사했다. 서울 25, 강원 17, 경기 43, 인천 1, 경남 3개다. 다른 전국 시군구는 이번 점검 범위가 아니며 녹색으로 표시하지 않는다.

`storage/region_readiness_audit.json`에 지역명·코드별 검사 내역과 실패/미검증 이유를 보관한다. 화면 API는 내부 경로를 제거한 결과만 제공한다.

- data_ready: 최신성 규칙, ML 사용 가능 상태 및 7개 지표, SQL 전국 비교 및 peer, 허용 공식 사례 4개 이상 조회 통과.
- verified: 위 항목과 최신 저장 기획안의 승인·명시적 방문/소비 목표·사업기간 전망·학습기간 일치 및 Word/PPT 생성 검증까지 통과.
- 초록색은 verified에만 적용한다. 미래 LLM 호출 성공률 또는 모든 사업의 모든 자료를 100% 보장하지 않는다. 새 제안서의 인허가·참여기관·운영 단가 등은 별도 확인이 필요하다.

## 현재 결론

89개 지역에서 이번 데이터 조회 기준은 통과했지만, 아직 초록색으로 확정할 지역은 없다. 춘천·원주 등 저장 기획안에 목표 시나리오가 누락되어 있다. 다른 지역은 실제 생성·검수·출력을 아직 확인하지 않았다. 기본 목표율을 넣거나 미검수 기획안을 승인 상태로 바꾸지 않았다.

전국 공통 목표 KPI 산정·저장·출력 연결 보완 및 실제 생성 검증은 남은 작업이다. 이번 작업에서는 유료/로컬 LLM을 89번 호출하지 않았다.

## UI 변경

- 시군구명: 검증 통과만 초록색. 선택창 아래에 데이터 준비 상태와 누락 이유를 표시.
- 검사 파일 없음·실패·24시간 경과: 미검증으로 표시.
- 다음 달 숙박 지표: ‘10월 예상 숙박일’, 값 ‘평균 2.64일’ 형식. 숫자는 실제 저장 예측값을 유지.
