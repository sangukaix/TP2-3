후속 실행에는 공유폴더 연결이 필요 없다. MySQL은 정규화한 관측값·출처·전국 비교를, 지역별 Joblib은 예측을, 로컬 ZIP은 업종별 소비 등 원자료를 제공한다. 기획 입력은 선택 지역의 요약·ML 7개 지표·비교 지역·관광 현황 근거로 구성하며 ZIP 전체를 프롬프트에 넣지 않는다. 정책·사업 성과 문서의 RAG 역할은 유지한다. 이번 관광 통계 취합 자체가 새로운 성공 사례 문서를 추가한 것은 아니다.

기존 서울 바깥 ZIP과 지역별 관광 현황 ZIP은 기존 로컬 사본과 SHA-256이 동일했다. 이미 정규화한 관광 흐름·인기 장소·집중률 자료를 그대로 재사용한다.

## 병합 및 제외 기준

1. `region_code + year_month`가 같고 관측값도 같으면 한 번만 사용하고 출처 별칭을 기록한다. 동일값 중복은 4,272행이었다.
2. 기존 값이 비어 있고 새 값에 출처가 있으며 나머지 값·지역 정체성이 일치할 때만 `--fill-missing`으로 보완한다. 기존 비어 있지 않은 값을 바꾸는 충돌은 자동 반영하지 않는다. 이번 병합의 미해결 관측 충돌은 0건이다.
3. 고양·부천·성남·수원·안산·안양·용인·화성·창원·포항·전주·천안·청주 **시 전체** 자료는 숙박 목적지 검색 지표가 부족하다. 자료가 갖춰진 하위 구는 개별 지원한다. 화성 신설 4개 구는 공통 월이 5개이므로 ML 생성 대상에서 제외했다. 원본과 검증 가능한 월별 통계는 보관한다.
4. 7월 개편 명칭은 [행정안전부 2026-07-01 코드 공지](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=127039)와 공식 첨부 ZIP을 추가 확인했다. 코드 사본은 `data/source_snapshots/official_codes_20260701/jscode20260701.zip`, SHA-256은 `0b9f143fb6e43657ff72c863ac1412cc4be43e79dce323aac602fb7754663898`이다.
5. 해당 31개 폴더는 공식 명칭·코드 확인을 마쳤다. 10개에는 ML 학습용 연도별 숙박 ZIP이 없고, 17개는 구 코드 자료의 30개월·7개 지표와 동일했다. 광주 4개 구는 2026-06 소비액만 차이가 있었다. `administrative_change_audit.json`에 별도로 기록했으며 동일 지역을 신·구 코드로 중복 학습·비교하지 않았다. 현재 운영 관측 자료는 **2026-06 기준 구 행정코드**를 유지한다. 신 코드로 과거 자료를 자동 치환하지 않는다.

## 코드 변경과 검증

- `prepare_team_snapshot.py` → `train_team_snapshot.py` → `activate_team_snapshot.py`: 로컬 코드·수치 검증, 별도 경로 학습, 실제 원본으로 6개월 예측 재검증, 모델 파일 배치 후 등록표 원자적 교체. 기존과 다른 모델 파일이 있으면 덮어쓰지 않는다.
- `region_registry.py`: 카탈로그 변경을 다음 조회에 반영한다. 서버 요청 중 학습하지 않는다.
- `main.py`: 시도 비교와 기획 스냅샷의 지역명은 폴더 계층이 아닌 등록표 기준으로 해석한다. 새 평면 보관 경로에서도 같은 시도 비교가 동작한다.
- `audit_all_regions --data-only`: HTTP 서버·LLM 생성 없이 생성 입력을 전수 점검한다. 품질 승인 상태는 생성하지 않는다.
- Python 관련 테스트 49개, React 테스트 17개, 프론트 lint·production build 통과.
- 225개 교체·추가 경로는 원본과 모델 fingerprint 및 6개월·7지표 예측을 확인했다. 전체 250개 지역의 생성 입력 점검도 통과했다.
- 실제 API 계약으로 목록 250개와 유성구·제주시·양양군·창원 의창구 대시보드 200 응답, 시도·전국 비교를 확인했다.
- 브라우저에서 실제 API 응답을 재생해 목록 250개, 유성구 선택·유지·생성 버튼 활성화를 확인했다. 생성 POST는 차단했으며 실제 기획서 생성 시험은 아니다.
- 신학습 1,127개 지표의 선택 모델은 전년 동월 기준 662개, LinearRegression 268개, RandomForestRegressor 197개다. 선택은 Validation 기준이다. Test에서 기준모델보다 불리한 지표 361개가 있어 모든 지역의 예측 정확도가 개선됐다고 주장하지 않는다. 해당 신뢰도는 기존 ML 근거 계약에 유지한다.

## 실행 시 확인할 점

자료 점검은 250개 모두 통과했지만, 이번 연결 조회에서 Qwen·Gemma 준비 상태는 false였다. 따라서 초록색 `준비됨`은 로컬 모델 연결까지 확인됐을 때 표시된다. 연결을 우회하거나 OpenAI로 유료 대체하지 않았다. 실행 중인 개발 서버는 변경 코드를 로드해야 하므로 필요하면 기존 `start-dev.ps1`로 재시작한 뒤 화면을 새로고침한다. 실제 모델 응답과 최종 기획서 품질은 별도로 확인해야 한다.
