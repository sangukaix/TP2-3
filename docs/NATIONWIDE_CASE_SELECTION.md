# 전국 사례 탐색·지역 적용 정책

## 목적

같은 시도의 사례를 우선 보되 그 안에 가두지 않는다. 서울·다른 시도의 사례도 실제 운영 조건이 맞으면 비교한다. 전국 사례를 모두 학습했다는 뜻은 아니다.

```text
선택 지역 관측 + 검증된 peer
  → 같은 시도 사례
  → 타시도 유사 지표 지역 사례
  → 전국 사업·서로 다른 운영 방식
  → 공식 원문 확인
  → 유지/제외/축소/변경 조건 비교
  → Qwen 후보 선정 → Gemma 실행 기획 → 검수
```

## 코드와 제한

- `ai_server/app/case_scope.py`: 시도 별칭·지역 식별, 전국 탐색 정책, 출처 중복 제거, 최대 8개 비교 카드 선정, 선택/제외 수 기록.
- `rag_store.search(nationwide_cases=True)`: 타시도의 `case_study`, `case_study_budget`만 검색 범위를 확장. 타지역 일반 정책·시설을 선택 지역 사실로 가져오지 않는다.
- Chroma 의미검색도 지역/문서 유형 필터를 Top-K 전에 적용한다. 학생 모드는 유료 임베딩 없는 기존 키워드 조회를 유지한다.
- `case_study_agent.py`: RAG 후보를 전달하되 검수된 정형 사례로 자동 승격하지 않는다. 최신 검수 카드와 중복된 오래된 RAG 요약은 제외한다.
- `evidence_agent.py`: 제한된 무료 검색 질문 안에서 선택 지역 질문과 전국 비교 질문을 배치한다. 검색 요약은 확정 근거가 아니다.
- `local_prompts.py`: OpenAI뿐 아니라 Qwen/Gemma도 같은 전국 사례·적용 조건 규칙을 받는다.

## 비교 해석

현재 peer는 방문 규모·소비/방문 집계 비율·숙박 비율·숙박일 등의 관측 거리로 선택한다. 주민등록 인구가 비슷하다는 뜻이 아니다.

인구 비교에는 별도 공식 인구 자료와 기준월이 필요하다. 인구가 같아도 접근성·여행 목적·계절·운영 인력·예산·업체 참여가 다를 수 있다. 인구 비례로 매출 증가율과 사업비를 이전하지 않는다.

`retrieval_context`는 왜 검색 후보에 들어왔는지 설명할 뿐, 그 사업의 적합성 점수나 예상 효과가 아니다. 인근 사례 미확보는 해당 지역에 실제 사업이 없다는 뜻도 아니다.

## API/비용

- `planning_decision`에는 선택/비교 후보와 적용 조건을 유지한다.
- 조사 패키지의 `case_search_policy`, `case_search_coverage`와 `agent_trace`의 `national_case_selection`에 실제 탐색 범위·후보 수를 기록한다.
- 학생 절약 모드의 유료 최종 검수 최대 1회, 자동 유료 조사·폴백 차단은 그대로다. 검색 범위 확대는 OpenAI 예산 확대가 아니다.
- 사례 등록 수보다 운영지침·결산·성과 정의의 품질이 중요하다. 이번 원주 후속 자료 목록은 [점검 문서](WONJU_PROPOSAL_QUALITY_AUDIT_20260907.md)를 따른다.
