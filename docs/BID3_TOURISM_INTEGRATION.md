# bid3 UI와 관광 분석 기능 통합 기준

## 가져오는 것

- 224px 고정 사이드바, 64px 상단바, 최대 1360px 본문 폭
- 흰색 카드, `#e1e7ef` 테두리, `#2563eb` 핵심색, 작은 그림자
- 제안서 작업공간의 본문 + AI 보조 패널 구성
- 향후 기획서 프로젝트 목록, 템플릿 선택, 미리보기, Word/PPT 출력 흐름

## 가져오지 않는 것

- G2B 입찰공고, 회사정보, 추천공고, 결제·구독 화면
- Django 인증과 SQLite DB
- 관광 데이터 규칙을 거치지 않는 입찰용 프롬프트

## 관광 화면 흐름

```text
지역 선택 지도(메인)
  → 핵심 KPI와 최근 12개월 방문·소비 그래프
  → 소비·체류 진단
  → 5-Agent 전략 생성
  → AI 도우미 설명·공식 사례 조사·수정안 제안
  → 사용자 확인 후 수정안 적용
  → Word/PPT 기획서 출력
```

## AI 도우미의 데이터 경계

- 정확한 월간 값: `data/raw`에서 서버가 다시 계산한 snapshot
- 현재 기획안: 5-Agent가 만든 구조화 JSON
- 정책·사례: 허용 공식 도메인의 웹 검색과 검수된 RAG 문서
- 자동 변경 금지: 챗봇은 patch만 제안하며 React의 적용 버튼을 눌러야 현재 보고서에 합쳐진다.
- 허위 성과 금지: 다른 지역 성과는 참고사례이며 선택 지역의 예상 성과로 바꾸지 않는다.
