# Codex 첫 요청문

아래 문장을 복사하여 프로젝트 폴더를 연 Codex에게 보낸다.

```text
프로젝트 루트의 AGENTS.md와 docs 폴더의 모든 Markdown 문서를 순서대로 읽어줘.
이 프로젝트는 한국관광 데이터랩 공모전용 STAY-UP AI야.

아직 전체 웹앱을 만들지 말고, 첫 단계로 실제로 사용 가능한 한국관광 데이터랩 파일을 기준으로 데이터 타당성 검토 계획을 만들어줘.
확인할 데이터 파일, 필수 컬럼, 최소 필요 기간, 지역코드·기준연월 결합 방법, 다음 달 방문객 수 예측이 가능한지 판단하는 기준을 표로 정리해줘.
확인 전에는 가짜 데이터나 가정으로 ML·DB·화면을 구현하지 말아줘.
수업에 나오지 않은 라이브러리·방법이 필요하면 먼저 이유를 설명하고 물어봐줘.
```

## 실제 데이터 파일을 넣은 뒤의 요청문

```text
data/raw 폴더에 넣은 실제 데이터랩 파일을 읽고, 원본은 수정하지 말고 데이터 목록과 컬럼·기간·결측치·지역코드·단위·결합 가능성을 점검해줘.
docs/DECISIONS.md의 미정 사항 중 데이터로 확정 가능한 항목을 제안해줘.
다음 단계는 EDA와 전처리 코드만 최소한으로 만들고, 실행 결과를 보여줘. 아직 웹 화면이나 AI 전략 기능은 만들지 말아줘.
```
