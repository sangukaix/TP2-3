## 공통 적용과 출력

- 웹·PPT·Word는 같은 `prepare_idea_report → build_operating_target`를 사용한다. 명시적 사용자 목표와 견적은 유지하며 수동 견적 재배분 시 자동 시나리오 연결 설명은 제거한다.
- 제주/대전 모두 17장, 같은 크기·공통 테마·순서다. 선정 사례에 실제 전후 수치가 있으면 막대그래프, 없으면 공식 운영 내용과 이용 흐름을 표시한다. 타지역 숫자를 빌려 그래프를 만들지 않는다.
- 문경 축제 카드에 245,750→256,570명, 개최 10→9일 및 일평균 변화가 표시된다. 해당 행사 사진 대신 쓰인 문화행사 참고사진은 서울 중구 정동야행이라는 실제 장소·출처를 표시한다.
- 관광 API의 검증된 사진 바이트를 URL별로 보관해 본문·표지·Word가 재사용한다. 캐시가 손상되면 검증 후 다시 받으며 타지역 사진으로 위장하지 않는다.
- 변경 PPT/Word를 Office에서 렌더하고 사례 카드·운영 흐름·견적 표·Word 견적 페이지를 확인했다.

## 실제 응답 판독

- Qwen은 문경찻사발축제, 강진 반값여행, 디지털 관광주민증을 비교하고 문경을 참고한 `대전광역시 서구 문화관광축제 운영`을 선택했다. 강진만 고정 선택하도록 되어 있지는 않으며 새 축제가 모델의 비교와 선택에 실제 등장했다.
- **선정 설명 품질은 미달이다.** 문경 운영과 대전 서구의 구체적 차이·공간·방문 행동을 설명하지 않고 ‘콘텐츠를 제공해 방문과 소비를 증대’한다는 문장을 반복한다. 문경의 실제 전후 수치와 일수 변화도 선정 논증에 활용하지 않았다. 검색량·SNS 언급이 낮다는 비교 기준 없는 판단이 있다.
- 예산 문장에는 1,000명×50,000원+홍보 1,000,000원인데 합계 55,000,000원이라고 적어 4,000,000원이 설명되지 않는다. 새 공통 견적 함수는 이 LLM 합계를 채택하지 않는다. 성공 10%/15%, 중단 5% 등 출처 없는 기준과 데이터랩을 매일 측정자료로 표현한 부분도 남았다.
- 자동 검사의 8개 주요 지적과 별개로 위 본문을 직접 확인했다. 이번 실제 테스트의 성공 범위는 긴 축제 원문 전달과 후보 활용 확인이며, 최종 기획 품질 승인이 아니다. Gemma 본문/Reviewer/전체 보고서 재생성은 실행하지 않았다. 추가 반복 실험은 하지 않았다.
- 배포 출력용 검토 파일은 **기존 환급 기획서의 공통 견적·디자인 수정본**이다. 진단에서 새로 나온 문경 축제안을 승인하거나 저장본으로 교체한 파일이 아니다.
