# 개인 노트북 Qwen 전환 (2026-09-16)

사용자가 설치를 확인한 태그로 개인 `.env`를 변경했다. 공통 라우터가 모든 시군구에 적용한다.

| 설정 | 새 설정 | 복구 설정 |
|---|---|---|
| `OLLAMA_QWEN_MODEL` | `qwen3.8:27b` | `qwen3:14b` |
| `OLLAMA_QWEN_CONTEXT_LENGTH` | `70000` | `40960` |

local_first의 검색 질문 설계, 적용성 비교, 로컬 검수, 설명 챗봇에 적용한다.
Gemma 본문·보완, OpenAI 조사·최종 검수, 유료 한도·출력 상한·근거 보존 검사는 유지한다.
팀원용 `.env.example`에 미설치 모델을 강제하지 않는다.

## 적용·복구

진행 중 기획 생성이 없을 때 `TOUR AI 8112` 창에서 Ctrl+C로 종료하고 프로젝트 루트에서
`./start-dev.ps1`을 실행한다. 관리자 `/llm-control` 또는 `GET /ai/v1/llm/status`의
effective_routes에서 Qwen 모델명을 확인한다. 느리거나 품질이 떨어지면 위 두 항목을 복구
설정으로 되돌리고 AI 서버를 재시작한다. 기존 모델은 삭제하지 않는다.
별도 실행 환경변수에 이전 값이 지정되어 있으면 `.env`보다 우선하므로 함께 확인한다.

65,536 요청과 실제 `/api/ps` 할당이 일치함을 후속 시험에서 확인했다.
설치 메타데이터의 지원 문맥은 262,144이다. 800,000은 지원 범위를 넘는다.
로드 크기는 약 20.25GB, size_vram은 약 10.22GB로 보고됐다. GPU 전용 실행은 아니다.

## 확인 범위

후속 사용자 요청으로 현재 요청 문맥을 70,000으로 변경했다. 새 환경을 읽은 라우터 설정은
확인했으며 아래 실측은 변경 전 65,536 시험이다. 70,000 실제 할당·속도는 아직 미검증이다.

새 환경을 읽는 라우터의 Qwen 4개 경로와 문맥, 나머지 모델·비용 정책 보존을 오프라인 확인했다.
초기 원격 조회는 자동 승인 검토 오류로 차단됐으나 후속 승인 시험에서는 접속과 설치를 확인했다.

- 짧은 JSON 응답: 22.15초(첫 로드 포함), 입력 95/출력 52토큰. JSON 형식과 계획/관측 구분은
  맞지만 `6×8×3×2×40`을 19,200으로 잘못 계산했다(정답 11,520). 단일 질문이며 전체 품질 비교는 아니다.
- 철원 로컬 재구성 입력: 29,809토큰을 55.54초에 수용했다. 출력은 시험용 1토큰 제한으로
  의도적으로 미완료다. 원래 실패 건의 새 유료 웹 근거는 포함하지 않으므로 해당 오류 재현 해결이나
  기획서 전체 품질 통과로 주장하지 않는다. 기존 파일·보고서는 변경하지 않았다.
- 131,072 확대는 하지 않았다. 현재 시험 입력이 65,536 내에 들어가므로 먼저 이 설정을 유지한다.
- 실행 중 AI 서버는 아직 `qwen3:14b`를 반환했다. 이번 시험은 새 `.env`를 읽는 별도 로컬 프로세스로
  수행했으며 웹 적용에는 위 재시작이 필요하다. 유료 API 호출은 없다.

실측 기록: `output/qwen38_validation_20260916/result.json`.

동일 질문·JSON 스키마·출력 256·think=false 조건의 기존 14B 비교는 8.34초였으나
정원을 7,200으로 계산해 역시 실패했다. 첫 로드·오프로딩 조건 차이가 있으므로 이 시간만으로
일반 속도 우열을 확정하지 않는다. 단일 산술 오류로 새 모델의 전체 기획 품질이 더 낮다고
결론내리거나 자동 복구하지 않는다. KPI·견적은 기존 코드 산식을 기준으로 유지한다.
비교 기록: `output/qwen38_validation_20260916/baseline_short.json`.

## 70,000 재시작 후 확인

사용자가 AI 서버를 재시작한 후 실행 중 8112 status의 Qwen 4개 경로가 qwen3.8:27b로 바뀐 것을 확인했다. 현재 설정을 읽는 별도 로컬 시험에서 최대 4토큰 응답을 요청했고 실제 /api/ps context_length=70000을 확인했다(16.6초, 입력 15/출력 3토큰). status API 자체는 문맥 값을 노출하지 않는다. 전체 기획서나 70,000 입력 부하 검증은 아니며 유료 호출은 0회다. 기록: output/qwen38_validation_20260916/context_70000.json. 위 미검증·이전 서버 설명은 변경 당시 기록이다.
