## 발견한 문제

### 지역코드 미확정 15지역

- 행정구가 있는 상위 시 집계: 고양시, 부천시, 성남시, 수원시, 안산시, 안양시, 용인시, 화성시, 창원시, 포항시
- 새 행정구 또는 데이터 미제공: 화성시 동탄구·만세구·병점구·효행구
- 행정명칭 변경 전 잔존 폴더: 강원도_강릉시

상위 시와 하위 구를 한 모집단에 중복 포함하면 비교와 모델 학습이 왜곡된다. 공식 지역코드표와 분석 단위를 확정하기 전에는 MySQL production fact에 적재하지 않는다.

### 원본 ZIP 검토 20건

일부 상위 시의 2026 인기관광지 또는 지역 집중률 ZIP이 실제 빈 ZIP이다. 파일 이름은 존재하지만 데이터가 없으므로 `0건`으로 처리하지 않고 `missing source data`로 기록한다.

### 같은 지역명 충돌

동구·서구·남구·북구·중구·고성군·강릉시는 이름만으로 구분할 수 없다. `region_code + year_month`가 확정되기 전에는 조인하지 않는다.

## ML 타당성 판단

- 상태: `provisional pass`
- 근거: 142지역의 핵심 target과 진단 feature가 30개월 동안 동일 schema로 존재한다.
- 제한: 지역별 독립 모델은 관측치가 짧으므로 과적합 위험이 있다. 모든 검증 지역을 사용하는 panel/global 모델과 지역별 seasonal-naive를 함께 비교한다.
- 필수 평가: 시간순 train/validation/test, seasonal-naive, LinearRegression, RandomForestRegressor, 지역별·전체 MAE/RMSE/MAPE.
- 사용 금지: 검증 시점 이후 공개값, 무작위 split, 빈 ZIP을 0으로 대체, 상위 시와 하위 구 중복 학습.

## 결론

핵심 데이터는 지역 비교, 파생 지표, 다음 달 예측을 설계하기에 충분하다. 그러나 아직 전체 전국 자료가 아니며 공식 지역코드와 상·하위 행정구 중복 문제가 남아 있다. 따라서 이번 결과는 MySQL/ML 구현을 시작할 수 있는 `provisional pass`이고, production 적재 승인은 지역코드 검증 후에 내린다.
